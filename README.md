# Antigravity Custom Skills

このリポジトリは、Google Antigravity（AGY）エージェントの振る舞いをカスタマイズ・拡張するための**カスタムスキル**を管理するプロジェクトです。

## 含まれるスキル

現在、以下のスキルが `skills/` ディレクトリ配下に定義されています。

### 1. clear-japanese-commit
* **目的**: わかりやすくプロフェッショナルな日本語のコミットメッセージを作成します。
* **特徴**: Conventional Commitsのフォーマット（`type(scope): subject`）に従い、「何」を「なぜ」変更したのかに焦点を当てた箇条書きの詳細なメッセージを生成します。

### 2. internal-project-review
* **目的**: プロジェクト全体の内部レビューを実行します。
* **特徴**: 疎結合性、保守性、ライブラリのサポート状況、ベストプラクティスといった様々な観点からコードベースを客観的に評価し、品質の向上をサポートします。

## スキルの追加・カスタマイズ

新しいスキルを追加する場合は、以下の手順に従います。

1. `skills/<skill_name>/` ディレクトリを作成します。
2. そのディレクトリ内に `SKILL.md` を作成します。
3. `SKILL.md` の先頭には必ず YAML フロントマター（`name` と `description`）を記述し、その下に具体的な指示やガイドラインをマークダウン形式で記述してください。
